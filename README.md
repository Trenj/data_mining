## Лабораторная работа №1. Поиск частых наборов объектов (алгоритм Apriori)

## Задание

Разработать программу, выполняющую поиск частых наборов объектов в заданном наборе
данных с помощью алгоритма Apriori. Список результирующих наборов должен содержать
сами наборы и значение поддержки для каждого набора. Параметры программы:

- набор данных;
- порог поддержки;
- способ упорядочивания результирующего списка (по убыванию поддержки или
  лексикографически).

На наборе данных `baskets.csv` (покупки в супермаркете) проведены эксперименты с
варьированием порога поддержки: 1%, 3%, 5%, 10%, 15%. Результаты визуализированы в
виде двух диаграмм:

1. быстродействие алгоритма на фиксированном наборе данных при изменяемом пороге
   поддержки;
2. количество частых наборов объектов различной длины при изменяемом пороге
   поддержки.

## Данные

`baskets.csv` содержит 7501 транзакцию (чеков) и 115 уникальных товаров. Каждая
строка файла это один чек: перечисленные через запятую товары, без заголовка и без
идентификатора транзакции. Кодировка файла `cp1251`.

## Реализация

Алгоритм Apriori реализован с нуля на Python (без сторонних библиотек для самого
поиска частых наборов), в `apriori_market_basket.ipynb`:

- `get_frequent_items` находит частые наборы из одного товара;
- `generate_candidates` строит кандидатов следующего размера и отбрасывает тех, у
  кого есть нечастое подмножество;
- `count_support` считает поддержку кандидатов по транзакциям;
- `apriori` связывает шаги в единый цикл и возвращает список
  `(набор объектов, значение поддержки)`, отсортированный по убыванию поддержки или
  лексикографически.

## Лабораторная работа №2. Поиск ассоциативных правил

Доработана программа из работы №1: по найденным частым наборам строятся
ассоциативные правила вида `антецедент → консеквент` с указанием поддержки
и достоверности каждого правила. Дополнительные параметры: порог достоверности,
способ упорядочивания (по убыванию поддержки или лексикографически).

Эксперименты на `baskets.csv`:

- **Часть А (проверочная):** поддержка 10%, достоверность от 70% до 95% с шагом 5%,
  правил нет (0 во всех точках): при поддержке 10% частыми остаются только
  7 одиночных товаров, парных наборов нет;
- **Часть Б (основная):** поддержка 2%, достоверность от 20% до 50% с шагом 5%,
  число правил падает (54, 29, 21, 13, 4, 1, 0),
  время конвейера почти постоянно (около 0.63 с).

Визуализация (в `lab2/`):

1. `runtime_vs_confidence.png` - быстродействие поиска правил
   при изменяемом пороге достоверности;
2. `rules_count_vs_confidence.png` - общее количество правил
   при изменяемом пороге достоверности.

Список для содержательного анализа: 21 правило при поддержке 2%
и достоверности 30% (все короткие: антецедент и консеквент суммарно 2 объекта, не более 7).
Основной эффект: вода как частый консеквент (минеральная вода в 17 правилах из 21,
следствие ее популярности 23.8%), а также продуктовые связки:
`говяжий фарш → макароны`, `креветки → макароны`, `гамбургер → яйца`.
Самое достоверное правило: `суп → минеральная вода` (confidence 0.456).
